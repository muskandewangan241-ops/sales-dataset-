This project analyzes a retail sales dataset (100 transactions) using Microsoft Excel.
The objective is to extract meaningful business insights from customer purchases across different cities, product categories, and payment methods.


      The dataset includes orders from cities such as:
New York
Los Angeles
Chicago
Houston
Miami
Dallas
Phoenix
Seattle
Boston
San Francisco

      Dataset Information

Total Records: 100 Orders

Columns Included:
Column Name 	-Description
Order ID	    -Unique transaction ID
Customer Name -Name of buyer
Product	      -Item purchased
Category	    -Product category (Electronics, Gadgets, Office, Accessories)
Quantity	    -Units purchased
Unit Price	  -Price per unit
Total Sales	  -Quantity × Unit Price
Order Date	  -Date of transaction
City	        - Purchase location
Payment Method- Credit Card, Debit Card, Cash, PayPal, Bank Transfer
  
   Project Objectives
Calculate total revenue 
Identify top-performing products
Analyze sales by category
Compare city-wise revenue performance
Evaluate preferred payment methods
Track monthly sales trends

       Tools Used
Microsoft Excel
Pivot Tables
Charts
Slicers
Conditional Formatting
